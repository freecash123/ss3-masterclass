# SS3 MasterClass

**"Learn. Practise. Test. Master."**

A premium, fully interactive SS3 education platform for Nigerian secondary school students.

## 🚀 Live Demo

Visit: [https://freecash123.github.io/ss3-masterclass](https://freecash123.github.io/ss3-masterclass)

## Created by Awoyemi Fawas

## Features

- 🎓 18 SS3 Subjects with full curriculum
- 📖 Interactive lessons with Read Aloud
- 🧠 CBT Exam system with timer
- 📊 Analytics & progress tracking
- 🔥 Study streak & achievements
- 🃏 Flashcards, Notes, Bookmarks
- ⏱️ Pomodoro Timer
- 🤖 AI Study Tutor
- 🌙 Dark/Light theme
- 📱 Mobile responsive

## Tech Stack

- Next.js 16, TypeScript, Tailwind CSS v4
- Framer Motion, Zustand, Recharts
- Lucide React Icons

## Getting Started

```bash
npm install
npm run dev
```
